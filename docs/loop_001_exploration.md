## 2. P131 の粒度問題(最重要の設計影響)

P131(所在行政区)は地物によって「中央区」直付けと町丁(築地 Q1201337・明石町 Q11512542 等)経由に分かれる。
実例: 勝鬨橋 → 中央区、築地本願寺・築地市場 → 築地、聖路加国際病院 → 明石町。

| 探索 | 件数 | P625 あり | 充足率 |
|---|---|---|---|
| `wdt:P131 wd:Q212704`(直付け) | 284 | 159 | 56% |
| `wdt:P131+ wd:Q212704`(推移的) | 535 | 351 | 66% |

→ **抽出は `wdt:P131+` を使う**。直付けでは築地・明石町の主要地物(本願寺・聖路加等)を取りこぼす。

- bbox 空間検索(`wikibase:box`)も有効。仮置き bbox 内で約 120 地物(駅・ホテル等のノイズ多数を含む)

## 5. 都オープンデータ 文化財一覧 CSV

- データセット: `t000021d0000000017`(文化財一覧、東京都教育庁)
  リソース: `https://www.opendata.metro.tokyo.lg.jp/suisyoudataset/130001_cultural_property.csv`
- **エンコーディング cp932**、36 列(国の推奨データセット準拠)。主要列:
  `名称 / 文化財分類 / 種類 / 住所 / 緯度 / 経度 / 所有者等 / 文化財指定日 / 説明 / 最終確認日`
- **緯度・経度列あり → ジオコーディング不要**(IMPLEMENTATION_GUIDE §7 の判断待ち 2 件目を解消)
- 全 248 行中、「中央区」該当は **1 件のみ**(一石橋迷子しらせ石標、住所=八重洲一丁目、
  35.683948/139.77088 — 築地・明石町 bbox 外、日本橋圏)
- → tokyo_od 系統(F-02)は汎用実装とし、**tsukiji-akashicho では 0 件でも正常**。
  日本橋拡張(P6)で効く系統として維持する
- `説明` 列は長文の解説文(CC BY)。転載はせず、事実情報(名称・座標・分類・指定日)のみ利用(AGENTS §2)

## 6. bbox の確定

- 仮置き東端 139.786 は佃・月島(将来エリア `tsukuda-tsukishima`)の地物
  (住吉神社 139.7833・佃天台地蔵尊 139.7836・佃島 139.7827 等)を含んでしまう
- **確定値: 緯度 35.658–35.674 / 経度 139.764–139.7815**。東端は隅田川中心線の近似で、
  佃・月島側の地物(経度 139.7826 以東)を候補プールから排除する。佃大橋(139.7811)は西詰側として残る
- 矩形の限界: 勝どき駅周辺(139.7765/35.6587)など川の東岸の一部は残留する。
  **bbox は粗い抽出フィルタ + Q-02 検証用であり、エリア帰属の正はレコードの area 列(キュレーション)**
