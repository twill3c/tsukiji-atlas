# loop_006 キュレーション検証手順書(人間レビュー用)

candidates: `data/curated/sites.csv` 42 件(全件 verified=false)。
**検証が済むまで 1 件も Gold に流れない**(Q-05)。Q-01 の 40 件以上は verified=true が対象のため、
低確信の却下が 3 件以上出た場合は追加候補が必要。

## 検証手順(1 件ずつ)

1. **実在確認**: 現地の碑・説明板・社寺が実在するか(中央区教育委員会の説明板・区文化財リスト・現地写真等)
2. **座標補正**: 地理院地図で目視し、lat/lon を碑・地物の位置に補正(現状は概略値)
3. **属性確認**: era(SPEC §4 の「主帰属」判定)・category・year・summary の事実関係
4. **verified=true に更新** → まとめて `data: verify coordinates` の専用コミット(GUIDE §2.3)
5. 公開前に summary の逐語一致チェック(Q-06)を全件実施し、結果をループログに記録
